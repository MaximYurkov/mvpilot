# MVPilot Frontend

Frontend-часть проекта MVPilot.

MVPilot - веб-приложение для создания и анализа продуктовых кейсов. Пользователь создаёт кейс, описывает идею продукта и получает структурированный результат анализа.

## Стек

- React
- TypeScript
- Vite
- ESLint
- Prettier

## Локальный запуск

Перейти в папку frontend:

```powershell
cd frontend
```

Установить зависимости:

```powershell
npm install
```

Запустить проект:

```powershell
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```

## Проверка кода

Запуск ESLint:

```powershell
npm run lint
```
